1. Executive Summary & Core Objective

Logistics operations present complex technical challenges including dynamic rate calculations, capacity-safe agent dispatching, and real-time status tracking. The Last-Mile Delivery Tracker solves these problems by providing an automated, database-driven platform for customers, delivery agents, and system administrators.

2. Feature Architecture & Custom Additions

A. Volumetric & Zone-Based Rate Calculation Engine

The billing engine evaluates parcel dimensions to determine their dimensional bulk, ensuring accurate logistics pricing:

Volumetric Weight (kg) = (Length (cm) × Width (cm) × Height (cm)) / 5000

The shipment is billed on the greater of actual scale weight and volumetric weight:

Billable Weight = Max(Actual Weight, Volumetric Weight)

After weight resolution, the system detects local vs cross-town connections:

  • INTRA-ZONE: Pickup and drop pincodes map to the same logical delivery zone.
  • INTER-ZONE: Pickup and drop pincodes belong to different delivery zones.

B. Capacity-Weighted Auto-Assignment

When an order is created, the system executes a geodetic dispatch calculation using Haversine distance, weighted by active concurrent capacity to balance agent workloads:

Dispatch Score = Geodesic Distance × (1 + activeCount / maxConcurrent)

The closest agent with the lowest capacity usage factor receives the assignment. This auto-assignment query is wrapped in an isolated database transaction with row-level locks (FOR UPDATE) to guarantee concurrency safety and prevent double-booking.

C. Failed Attempt Rescheduling

If an agent marks a shipment as FAILED (e.g., recipient unavailable), the system flags the order and notifies the customer. The customer can reschedule the shipment for a new date. Upon rescheduling, the old agent is released (their active workload capacity is decremented), and the auto-dispatch engine assigns the shipment to the nearest available agent for attempt number two.

D. SMTP Email Notifications & Live WebSockets

Real-time updates are driven by twin communication engines:

  • Nodemailer SMTP Integration: Sends automatic status transition emails to the customer's mailbox.
  • Socket.io WebSockets: Emits instant events to the customer interface, refreshing the visual tracking timeline without polling.

4. Database Schema Structure

Table Name Key Fields Purpose
User id, email, passwordHash, role Authentication & permissions role config.
Agent id, userId, status, currentLat, currentLng, maxConcurrent, activeCount, zoneCoverage Agent profiles, GPS coordinates, coverage regions, and workload count.
Zone id, name Logical logistics zones grouping delivery areas.
AreaZoneMapping id, pincode, areaName, zoneId Maps postal pincodes directly to logistics zones.
Order id, customerId, pickupPincode, dropPincode, length, width, height, actualWeight, orderType, paymentType, currentStatus, chargeBreakdown, agentId Main delivery contract, dimensional specs, billing snapshot, status state, and current assigned agent.
OrderStatusHistory id, orderId, status, actorRole, actorId, timestamp, notes Immutable audit log capturing all tracking updates.

5. Comprehensive Step-by-Step Operations Guide

A. Customer Dashboard Operations

  1. Register or login as a Customer.
  2. Click "Place New Order" to open the placement form. Pincodes load dynamically from the active database.
  3. Input addresses, coordinates, package dimensions, weight, payment type (Prepaid vs COD), and B2B/B2C type.
  4. Review the live cost breakdown calculated by the pricing engine. Click "Confirm & Place Order".
  5. Locate the order card in the grid and click it to view the live tracking page, progress bar, and audit logs.

B. Agent Dashboard Operations

  1. Log in as an Agent.
  2. Toggle status on the Profile Card (e.g., go Online to become AVAILABLE).
  3. Assigned orders appear instantly on your dashboard list.
  4. Progress orders by clicking "Mark as Picked Up", "In Transit", "Out for Delivery", or "Delivered/Failed".

C. Admin Control Panel Operations

  1. Log in as `admin@lastmile.com`.
  2. Manage Shipments: Monitor all orders, filter by status, manually re-assign agents (with capacity checks), or override status.
  3. Zone Boundaries: Register new shipping zones and map pincodes to zones.
  4. Rates & COD Config: Adjust rate cards and COD surcharges.
  5. Delivery Agents: Create agent accounts and reset agent passwords.
